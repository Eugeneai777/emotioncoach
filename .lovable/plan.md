# 冰山模型海报 v5 改版

在 `iceberg-v4.png` 基础上重绘一版高清海报 `iceberg-v5.png`（输出到项目文件区，可直接下载）。

## 一、删除的内容

- 底部 `自我关怀｜正念冥想｜循证疗愈` 整行
- 左下角 `参考书籍 李崇建·《萨提尔的对话练习》，2017` 一行
- 标题区 `从理解自己的需要开始`
- 标题区 `冰山理论`
- 冗余英文行：`ICARE PSYCHOLOGY`、右下角 `GAVES 逹綾` 等杂散字符
- 左侧 `维吉尼亚·萨提尔` 署名（属于冗余标注，一并清理）

保留的标题只有两行：红色 `冰山模型` + 红框 `你没有注意到的那70%`。

## 二、执行的 5 条优化

1. **量化对比**：水平面上方标 `外显 30%`，下方标 `内隐 70%`，一眼看懂比例。
2. **层级颜色递进**：冰山从「身体和情绪感受」到「我是谁」由浅到深渐变，越深越暗，视觉上形成"往下沉"的引导。
3. **「我是谁」做成视觉终点**：红色加粗 + 红色描边标签框，右侧配一句副标 `所有行为的源头`。
4. **左侧引导语列**：沿冰山左边加一条竖向引导 `你看到的 / 你在意的 / 你需要的`，对应外显层、中间层、深层。
5. **底部行动出口**：替换被删除的那行，改为一句号召 `测一测：你的冰山下藏着什么？` + 右侧留出二维码位（占位方框，后续可替换真实二维码）。

## 三、右侧新增（参照附件参考图）

在冰山右侧加一条纵向标尺：

```text
   易 30%
     ↑        外显的 · 可见的
  ───────  水平面
     ↓        内隐的 · 深藏的
   难 70%
```

上下箭头贯穿，`易 30%` 在顶、`难 70%` 在底，字号与配色跟主标题红色系统一。

## 技术说明

- 用 Python + Pillow 程序化绘制（不走 AI 生图，保证中文字形准确、无乱码、无水印）。
- 分辨率约 1800×2400，300dpi 级别清晰度。
- 中文字体使用系统 CJK 字体（Noto Sans CJK / 思源黑体），红色主色沿用现图的 `#C62828` 系。
- 生成后逐张视觉检查：文字不出血、不重叠、留白均匀，有问题即修正重出。
